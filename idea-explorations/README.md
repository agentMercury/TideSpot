## 2. 画面上每个元素的功能出处

示例图按现有 Score Tab 的**真实顺序**排布，逐项可追溯：

| 画面元素 | 现有实现 / 契约 |
|---|---|
| 返回 + 点位名 + 坐标 | `DetailScreen` 顶部栏（`onBack`、`spot.name`、`Format.coordinate`） |
| 水体类型（内陆水体 / 近海礁区） | `WaterBodyType` 字段的静态文本显示，非新控件 |
| DaySelector（今天/明天/后天/11-15） | `DaySelector` + `DaySelectorLogic.chips` |
| 源更新 — · 本机拉取 15:20 | `ts_detail_source_update`（源端更新未透出时显示 `—`，此处照实显示） |
| 五维 Tab（顺序固定） | `WaterBodyTabTitles.titlesInTabOrder`：钓鱼指数 → 水位/潮流 → 天气 → 水质 → 风浪/湖面风与水温 |
| 大号分数 | `ScoreMainCard`（取当日峰值；`—` 时走空态文案） |
| 档位胶囊（爆护窗口 / 很适合） | `ScoreBand.of` + `BandTitles`；色值取冻结五档色 |
| 五段色带图例 | `ScoreMainCard` 内 `ScoreBand.entries` 图例（五档色 + 文字） |
| 图表 / 数值表 切换 | `ts_detail_chart` / `ts_detail_table` 分段控件（`DetailScreen` 内既有实现） |
| 24 根逐时柱 | `HourChart(mode = BAR)`，24 点逐小时 |
| 柱上「窗口」条 | `WINDOW_THRESHOLD = 80` 叠加的窗口横条（本例内陆 87 触发，近海 74 不触发——照实留空） |
| 当日摘要 | `DailySummaryLine`：最高/最低 + 时刻（`ts_detail_summary_unit`） |
| 因子分解（时段/溶氧/气压/潮流 + 权重 + 衰减 ΠV） | `FactorBreakdown`（点选小时后展开）三区：因子行 / ΠV 明细 / 原始输入；本例展示因子行与 ΠV |
| 最佳窗口 Top10 | `ts_detail_top10` 按钮（F-3.5） |
| 免责声明 常驻条 | `ts_disclaimer` 入口条（S02 C06，56dp） |

**刻意未画**：免责 Sheet 内容、Top10 Sheet、现场校潮、水质实测录入、离线/陈旧条、天气 Tab 安全摘要卡——都在首屏之外或需要交互触发，示例图不展开。

## 5. 内陆 / 近海区分（四通道冗余，均为既有信息）

1. **底色**：湖绿 vs 钴蓝/深海蓝。
2. **水体类型文本**：坐标行「· 内陆水体」/「· 近海礁区」（`WaterBodyType`）。
3. **Tab 与因子**：`水位（无潮汐）/ 湖面风与水温`、因子「时段」 vs `潮流 / 风浪`、因子「潮流」——全部来自现有映射。
4. **装饰母题**：芦苇/荷叶/鱼群 vs 浪尖/礁/海鸥。

## 6. 验收标准

- [x] 3 个方向 × 2 水体 = 6 帧，390×844、2x 输出。
- [x] 画面元素 100% 可映射到现有代码/契约（见 §2），无新增功能模块。
- [x] 同方向两帧结构一致，仅配色/文案/水体相关内容切换，模块基线对齐。
- [x] 首屏完整读出：点位 → 日期/来源 → 五维 Tab → 分数/档位/图例 → 图表切换 → 24h 柱 → 摘要 → 因子 → Top10 → 免责。
- [x] 无文字溢出、遮挡、贴边裁切；底部预留安全区。
- [x] 内陆触发「窗口」条、近海不触发，与阈值逻辑一致。

## 7. 风险

| 风险 | 影响 | 概率 | 应对 |
|---|---|---|---|
| V2 拱形标题需逐字旋转，长点位名超弧长 | 中 | 中 | 兼容层做「超长回落水平标题」；先 `Canvas` 逐字旋转 PoC |
| V2 排线/噪点面积大，性能与包体上升 | 中 | 中 | 噪点固化为 512 tile；排线用 `drawLine` 循环 |
| 手写体（楷体）在各机型不可用 | 中 | 高 | 标题回退 `serif`；关键信息用系统黑体，不依赖手写体 |
| V2 为深底方向，与明暗主题冲突 | 中 | 高 | 视为「深色向」；选中后补米白纸底变体 |
| 三方向并行导致范围膨胀 | 高 | 中 | 仅示例图；选定 1 个再开完整版 |
