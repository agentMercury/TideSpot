## 创作原则
1. **不是贴图，是重新画**。5 张图只作美术语言参考，全部 UI 元素（鱼、浪、山、准星、卡片、Tab 图标、空状态鱼骨）均为矢量重绘，随版本参数化生成，无素材裁切拼贴。
2. **鱼形装饰替换**（呼应"把一些元素替换成鱼的形状"）：
   - 准星中心点 → 小鱼（海洋=咸水鱼 / 内陆=淡水鱼）
   - 顶部水体徽标 → 浪+贝+海鸟 ↔ 山+日+芦苇（并各含一条鱼）
   - 五个 Tab 图标 → 一排小鱼
   - 五档色带 → 递减鱼群（爆护 5 条 → 别去 1 条），恒配档位文字
   - Top10 入口 / 收藏标 / 设置版块标 → 鱼
   - 空状态 → 鱼骨；下拉刷新语义 → 鱼跃（备用母题）
3. **工程事实锁定**。四版共用同一份 `copy.json` frozen 文案与结构：Tab 序、免责 5 条、六徽标、DaySelector 52dp、水质 1×3、无底部 Tab、六版块设置。变的只有美术皮肤与双水体配色。
4. **手绘质感靠滤镜不靠贴图**：SVG `feTurbulence` 纸颗粒 + `feDisplacementMap` 描边毛边 + 非对称圆角 + 套印错位阴影；滤镜只作用于图形，不动文字清晰度。

## 边界
- 手绘概念稿，**非工程交付**：可编译色值落地时须回归 `TideSpotTheme.kt` / `ScoreBands.kt` / `ConfidenceBadge.kt`。
- 分数 / 时刻 / 点位为**版式示意**，非业务数据；源更新时间显示 `—`，未硬编码任何示意时刻。
- 档位恒带文字，不靠颜色单独编码（N-7 红线）。
