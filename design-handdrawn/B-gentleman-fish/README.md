## 视觉语言
克莱因亮蓝纯底 + 圆润拟人鱼（领带/条纹围巾/纽扣/圆眼/黄嘴）+ 轻纸颗粒 + Comic 手写标题

**鱼形母题**：拟人绅士鱼：西装领带 + 条纹 + 圆眼黄嘴，可做品牌 IP
