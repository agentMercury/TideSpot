## 每套详情页的「双水体」如何一眼区分
每版详情页都出**两张**（`detail-sea.png` / `detail-inland.png`），六重信号叠加：

| 信号 | 海洋 / 近海 | 内陆 / 湖泊 |
|---|---|---|
| 顶部鱼形徽标 | 双层浪 + 贝/帆 + 海鸟 | 尖山 + 圆日 + 芦苇 |
| 主色 | 冷蓝 / 藏青（复古版为藏青做旧） | 暖绿 / 墨绿（复古版为墨绿做旧） |
| 鱼种 | 咸水鱼（真鲷等） | 淡水鱼（鲤鱼等） |
| 第二 Tab | 潮流 | 水位（无潮汐） |
| 图表 | 潮高 · 潮流 | 水位 · 无潮汐 |
| 地点 / 坐标 | 青岛·小麦岛外海 | 千岛湖·中心湖区 |

换水体时**布局、组件、结构完全不变**，只换配色与上述语义内容——保证可对照、可维护。

## 冻结契约（四版完全一致，切版时是常量）
工程 theme 色与字阶 · 五档分数色语义与档位文字（爆护/很适合/可以/较差/别去）· 六徽标（实测/卫星/模型/估算/未校正/低置信）·
Tab 渲染序（钓鱼指数→潮流/水位→天气→水质→风浪）· DaySelector 52dp 两行 · 水质 1 行×3 卡 ·
免责恒 5 条原文 · 地图优先无底部 Tab · 六版块设置含 Copernicus 凭据与 API Key 正式启用 · 逐源隐私披露。

可变轴只有两个：**美术皮肤**（纸底/线条/字体/鱼形画法）× **水体配色**。

## 手绘质感怎么做的
全部矢量 + 滤镜，**无贴图**（改色改字不改质感）：
- `feTurbulence fractalNoise` → 纸张颗粒覆盖层（multiply 混合，不糊文字）
- `feDisplacementMap` → 卡片描边 / 鱼 / 地图线的毛边抖动
- 非对称 `border-radius` + `box-shadow` 套印错位 → 手绘方框与复古印刷感
- 系统手写字体：中文 KaiTi 楷体；英文 Georgia / Comic Sans / Gabriola / Impact / Ink Free（按风格分配）

## 鱼形装饰替换（"把元素换成鱼的形状"）
准星中心 · 顶部徽标 · 五 Tab 图标 · 五档色带（鱼数=档位）· Top10 入口 · 收藏标 · 设置版块标 · 空状态鱼骨，全部做成各版画风的鱼。

## 择优后怎么定
告诉我用哪版即可，例如：
- 「用 **B**」→ 我把 B 提升为正式手绘方向，按需补其余屏 / 深色全屏 / 图标。
- 「**C 的配色 + D 的鱼形**」→ 我按混搭参数重出一版。
- 「都再调一调」→ 指定方向（更简 / 更繁 / 换鱼种 / 换字体 / 加强某版母题）。

落选版**不会删**，随时可切回。选定前 `design-handoff/` 正式交付保持 v3.0.0 不动。
