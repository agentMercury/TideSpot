## 风格来源
- 图8 微信图片_20261112105652_8_163.jpg（三条抽象撞色鱼）

## 视觉语言
亮蓝/湖水底 + 蓝白黄橙红色块拼接 + 水彩毛边晕染 + 大留白 + Gabriola 极简标题

**鱼形母题**：几何色块鱼：三角头 + 撞色矩形 + 水彩晕染毛边

**适合**：清爽高级、装饰克制；最像现代插画 App，留白呼吸感最好
