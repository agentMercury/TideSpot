## 0. 一句话结论

工程 v1.16.0 的功能完成度**很高**——5 Tab、下拉刷新、陈旧/48h 不可用、因子分解、图表⇄数值表、Top10 时段筛选与自选时段、现场校潮、免责 5 条、地图准星三态、星标气泡卡、收藏搜索/排序/分组/批量、设置六版块均已落地。本次对照后：**9 条差异中，7 条转需求（3 项新增/落地、2 项口径对齐、2 项下线）、2 项仅记录**。绝大多数"完整 UI"里的屏，工程早已有对应实现，差异主要在**视觉外观**（属美化，不属功能需求）。

> **本轮需求变更（2026-11-12）**
> 1. `OPT-A-01`「用例/物种/权重」由"升级为可编辑"改为 **从设置页删除该功能**（不实现编辑，工程删占位入口）。
> 2. `OPT-A-02`「API Key」由"接线/改文案"改为 **从设置页删除该功能**（覆盖此前 DECISION-API-KEY 的"正式启用"裁定）。
> 3. 新增 `OPT-A-09` **提供换皮肤（UI 样式切换）功能**，首版仅内置手绘 A 一款，B/C/D 不作为皮肤；扩展方式见 `SKIN-DESIGN-SPEC.md`。

## 1. 方法与分类

逐屏逐功能对比「设计稿表达的功能/交互/状态」与「工程真实实现」，每条标注代码证据。分四类：

| 类别 | 含义 | 处数 | 是否转需求 |
|---|---|---|---|
| `ui_new` | UI 已表达、工程未实现或仅占位 | 3 | ✅ 转新增/落地需求 |
| `ui_remove` | 产品决策：从 UI 下线并清理工程入口 | 2 | ✅ 转下线需求（本轮新增类别） |
| `mismatch` | 双方都有，但交互口径/视觉语义不一致 | 2 | ✅ 转对齐需求 |
| `code_ahead` | 工程已实现（或更强），UI 仅补齐/对齐 | 2 | ⛔ 仅记录，不转需求 |

优先级：`P0` 影响核心数据可信度或合规红线（本次 **0 条**）；`P1` 体验/完整度明显缺口（2 条）；`P2` 增强、下线或视觉文案层（7 条）。

## 3. 转需求项（7 条，逐条可验收）

### OPT-A-01 · P2 · 从设置页删除「用例 / 物种 / 权重」功能

- **来源屏**：`settings`（设置页 · 用例·物种·权重版块）
- **工程现状**：`SettingsScreen.kt:157-163` 仅一行占位 `Text(stringResource(ts_placeholder_v11))`，注释「占位 v1.1」，无真实可交互入口；设计稿画有「垂钓用例 / 物种预设」版块。
- **目标**（用户决策，覆盖"升级为可编辑"）：从 UI **下线该功能**——移除设置页「用例 · 物种 · 权重」整块版块；工程侧删除对应占位 Composable 与占位文案资源，不留空壳入口。**算法侧场景预设 JSON 与 F-3.4 权重逻辑保持不变**（只移除用户可见/可改入口，不改评分默认值）。
- **验收**：1. 设置页不再出现该版块与占位文案；2. 工程无残留死代码/死资源；3. 评分默认用例/权重行为不回归；4. 中英文案同步移除，无孤儿字符串。
- **工程落点**：`SettingsScreen` 删 section；清理 `strings.xml` / `strings-en` 相关条目；`HourlyScoreStore` 场景预设默认值不动。
- **需求依据**：用户决策 2026-11-12（原 SRS §6.4 / F-3.4，功能不实现、仅下线入口）。

### OPT-A-02 · P2 · 从设置页删除「API Key（可选）」功能

- **来源屏**：`settings`
- **工程现状**：`SettingsScreen.kt:165-179` 有输入框与保存按钮（写 SharedPreferences），文案明确「当前无消费方，仅保存备用·不入库不上传」，注释仍写「占位」；设计稿画有「API Key（可选）」版块与「正式启用」角标。
- **目标**（用户决策，**覆盖此前 `DECISION-API-KEY`「正式启用」裁定**）：不做接线/改文案，从 UI **下线该功能**——移除整块版块含「正式启用」角标；工程侧删除输入/保存逻辑与相关文案资源；已保存的 Key 做一次性清理（读 SharedPreferences 后清除，不上传、不残留）。
- **验收**：1. 设置页不再出现该版块/角标/输入框；2. 工程删除输入/保存 Composable 与 `SettingsState.apiKey` 相关字段；3. 已存 Key 有一次清清理路径且确认不入库不上传；4. 中英文案与隐私披露中 Key 表述同步移除。
- **工程落点**：`SettingsScreen` 删 section + 保存逻辑；清理 SharedPreferences 旧值；清理中英文案与隐私披露。
- **需求依据**：用户决策 2026-11-12（覆盖 `DECISION-API-KEY`）；原 SRS §5.7 / N-5。

### OPT-A-03 · P1 · 深色模式增加应用内手动开关

- **来源屏**：`dark-map` / `dark-favorites` / `dark-detail`
- **工程现状**：`TideSpotTheme.kt:89` `darkTheme = isSystemInDarkTheme()`，**仅跟随系统**；设置页显示版块无深色选项（grep `darkMode|themeMode` 无命中）。
- **目标**：设置页显示版块增加「深色模式：跟随系统 / 浅色 / 深色」三选，持久化并注入 `TideSpotTheme`；底图随深色切 Dark Matter 样式。
- **验收**：三选持久化；手动选择与系统设置解耦；底图/卡片/冻结语义色按深色 token 切换；冻结语义色对比度 ≥4.5:1（CHG-56）。
- **工程落点**：`SettingsState` 增 `themeMode`；`MainActivity` 读取传 `TideSpotTheme(darkTheme=)`；`MapScreen` 样式三选联动。
- **需求依据**：SRS §8.2-6；`screens.json DV04`；`TideSpotTheme.kt`。
- **与换肤的关系**：明暗是**独立于皮肤的轴**，与 OPT-A-09 正交，互不重置（见 `SKIN-DESIGN-SPEC.md` 三轴正交）。

### OPT-A-04 · P1 · 地图页「全部收藏 Top10」入口语义对齐

- **来源屏**：`ov01-top10` / `map-sea` / `favorites`
- **工程现状**：SRS §8.1（CHG-28）明确 Top10 入口**进收藏页并展开跨点 Sheet**，地图本点 Top10 需详情上下文、本期不做；工程 `DetailScreen`/`FavoritesScreen` 有 Top10 Sheet，但 `MapScreen` **无** Top10 入口。而设计稿在地图页也放了「全部收藏 Top10」横幅。
- **目标**：统一口径——地图页横幅改为「跨点 Top10」并跳转收藏页展开（或移除地图页本点 Top10 的暗示）；详情/收藏保留本点/跨点 Top10。
- **验收**：地图横幅跳转与文案一致；跨点 Top10 每项带点位名；无 ≥60 分窗口走兜底文案不造假；时段筛选四 Chip 可用。
- **工程落点**：`MainActivity` 导航 `onTop10` 回调；`MapScreen` 顶部横幅文案与点击。
- **需求依据**：SRS §8.1 / F-3.5 / §6.6；`screens.json OV01`。

### OPT-A-05 · P2 · 四态状态条视觉强调等级对齐状态语义

- **来源屏**：`state-offline` / `state-stale` / `state-unusable-48h` / `state-degraded`
- **工程现状**：`DetailScreen.kt:202` 有 `StaleBanner`（3h/6h TTL、≥48h 不可用）；设计稿为四态定义了区分色（离线灰 / 陈旧黄褐 / 48h 暖红最醒目 / 分维降级藏蓝），工程是否有四态分级视觉 token 需实现方核对。
- **目标**：为四态定义清晰视觉等级 + 文案单源：48h 用警示色且禁用数据操作；陈旧显示缓存时刻；离线/分维降级可继续读缓存。色值取主题 token（换肤时随皮肤变，但语义等级不变），不硬编码。
- **验收**：四态文案取 `TideSpotStrings`；48h 态最醒目且不可当正常数据用；状态条插入不遮挡 Tab/DaySelector；色值满足对比度。
- **工程落点**：`StaleBanner` 扩展 state 入参 + 主题 token（如 `TideSpotStatusColors`，纳入皮肤 token 集）。
- **需求依据**：SRS §6.7 / F-3.6；`screens.json C17`；`FO-03`（token 集中化）。

### OPT-A-06 · P2 · 设置页补 fetch_log（频控 / 请求可见）入口

- **来源屏**：`settings`
- **工程现状**：SRS §5.6 / N-6 要求「频控可见（fetch_log）」，设计稿数据与网络版块含该项；`SettingsScreen` 显示版块为预取/逆地理，未见 fetch_log 查看入口。
- **目标**：数据与网络版块增加「请求日志 / 频控」入口，展示最近请求（源/时刻/状态/是否命中频控），遵守 §12 红线源不入代码。
- **验收**：入口可达；日志不泄露密钥；频控命中可见；可清空本地日志。
- **工程落点**：`SettingsScreen` 增条目 + 复用仓库层请求记录（若已有）或新建只读日志。
- **需求依据**：SRS §5.6 / N-6 / §12。

### OPT-A-09 · P2 · 提供换皮肤（UI 样式切换）功能，首版内置手绘 A 一款

- **来源屏**：`settings`（「外观 · 皮肤」入口）+ 全屏视觉生效
- **工程现状**：`TideSpotTheme.kt` 仅提供 Material 3 Light/Dark `ColorScheme` + `TideSpotShapes` / `TideSpotTypography`，样式单套写死，无「皮肤/样式」抽象层与切换入口；设计侧本次仅产出手绘 A（复古户外）一款视觉，**B/C/D 是独立风格探索、不作为皮肤，本轮不并入**。
- **目标**（用户决策新增）：新增「皮肤（Skin）」抽象层与切换能力——
  1. 工程侧把 **颜色 / 字体 / 形状 / 纸张质感 / 鱼形装饰** 抽成可替换的皮肤 token 集（逐项清单见 `SKIN-DESIGN-SPEC.md`），注入 `TideSpotTheme`，默认加载手绘 A；
  2. 设置页新增「外观 · 皮肤」入口，展示当前皮肤卡片、可预览、可切换；
  3. **首版仅内置手绘 A「复古户外」一款**，其余槽位明确标「即将推出 / 敬请期待」占位，不塞 B/C/D、不伪造可选项；
  4. 换肤**只替换视觉 token**，不得触碰冻结契约（见第 5 节逐项）；
  5. 明暗（OPT-A-03）为**与皮肤正交的独立轴**，二者可组合、互不重置。
- **验收**：
  1. 设置页「外观 · 皮肤」入口可达，显示当前皮肤 = 手绘 A 复古户外与预览缩略；
  2. 皮肤 token 集可注入 `TideSpotTheme`，切换后全屏视觉一致生效、无单屏漏切；
  3. 首版只有 A 一款，其他槽位为「敬请期待」占位、不可误点为空功能；
  4. 换肤前后冻结契约逐项回归通过（五档/六徽标语义色仍取 `ScoreBands.kt` / `ConfidenceBadge.kt` 单源）；
  5. 皮肤与明暗正交：切皮肤不重置明暗、切明暗不重置皮肤，各自持久化；
  6. 新增皮肤按 `SKIN-DESIGN-SPEC.md` 接入清单即可扩展，无需改业务 Composable。
- **工程落点**：新增 `core/ui/.../skin/TideSpotSkin.kt`（皮肤 token 数据类 + A 实例 + 注册表）；`TideSpotTheme` 增 `skin` 参数并派生 ColorScheme/Shapes/Typography；`SettingsState` 增 `skinId` 持久化；设置页「外观·皮肤」入口 + 选择页（首版 A + 占位）。
- **需求依据**：用户决策 2026-11-12；`SKIN-DESIGN-SPEC.md`；`TideSpotTheme.kt`；OPT-A-03（明暗独立轴）。

## 5. 冻结契约（本次完整 UI 与换皮肤均未改动、也不应改动）

1. Tab 渲染序：钓鱼指数 → 潮流(水位) → 天气 → 水质 → 风浪
2. 免责恒 5 条原文（工程 D11「现场校潮」长文为准）
3. 五档分数色 = `ScoreBands.kt`、六徽标色 = `ConfidenceBadge.kt`（冻结单源，**不进皮肤 token**）
4. DaySelector 两行 52dp；水质 1 行 × 3 卡（水温/溶解氧/浊度，pH 已删）
5. 地图优先、无底部 NavigationBar；准星唯一选点真源 F-1.3
6. 双水体六重区分：徽标 / 配色 / 鱼种 / 第二 Tab / 图表单位 / 地点（**换肤只改配色明度与装饰，六重区分方式不变**）
7. 示例分数 78、时刻、点位均为**版式示意**，非业务数据；源更新时间未透出显示「—」
8. **换皮肤（OPT-A-09）只替换视觉 token，以上 1–7 逐项不变**；明暗（OPT-A-03）为与皮肤正交的独立轴。
