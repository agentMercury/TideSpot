## 7. 2026-11-13 第二批落地（OPT-A-04 / 06 / 10 / 11）

- **背景**：2026-11-13 CARTO（Fastly）在实测网络 443 全超时 → 底图整片空白；OpenFreeMap 同数据同坐标系 1.5s 可达。
- **实现**：新增 `MapProvider`（`OPENFREEMAP` / `CARTO`，默认前者）+ `MapProvider.styleUrl(style)` 映射；
  `settings.mapProvider` 持久化；设置页「地图来源」下拉（遍历枚举，**未来加源只加一项**）。
- **唯一出口**：`SettingsLogic.resolveBasemapUrl(state, darkTheme)` = provider × 生效样式；业务屏禁自拼 URL。
- **红线**：`MapStyle` 枚举名是持久化值，禁止改名（老配置会失配）。
- **验收**：下拉可切；切换即时生效；样式三选与「未改过跟明暗」逻辑不受影响。

### OPT-A-11 · 底图加载失败提示　P1　✅ 已完成
- **背景**：瓦片源不可达时是纯白，用户无法判断是坏了还是没网。
- **实现**：`MapScreen` 在 setStyle 后 1.5s 用 `HttpURLConnection`（6s 超时）探活样式源；失败 → 顶部 `errorContainer` 提示条
  「底图加载失败，点位与数据不受影响」+「重试」（自增 tick 强制重设样式并重新探活）。探活不阻塞首帧。
- **验收**：切到 CARTO → 提示出现且可重试；切回 OpenFreeMap → 提示消失；点位/潮汐/收藏功能不受影响。

### OPT-A-04 · 地图 Top10 语义对齐　P1　✅ 已完成
- **实现**：地图横幅文案对齐设计稿「全部收藏 Top10 · 最佳窗口」（跨点语义，零本点暗示）；
  收藏页跨点 Sheet 补设计稿 OV01 的**时段筛选四 Chip**（全部 / 接下来 24h / 本周末 / 自选）+ **≥60 分门槛** + **空态**。
- **逻辑**：`Top10TimeFilter` 从 `feature:detail` 上提到 `core:domain`（纯逻辑共用），新增 `intersects()`；
  新增 `CrossTop10Filter`（门槛 + 时段过滤，JVM 锁测试 5 条）。**无 ≥60 分窗口时显示空态，禁止兜底造假**。
- **验收**：横幅跳转与文案一致；每项带点位名；空态文案；四 Chip 可用；自选时段可填日期与起止。

- **实现**：新增 `MapStyleChoice`（`FOLLOW_THEME` / `COLOR` / `PLAIN` / `DARK`，`style: MapStyle?`）；
  设置页四选，`跟随主题` ⇔ `mapStyleExplicit = false`，其余 ⇔ `withMapStyle`（写样式 + explicit = true）。
- **为什么不塞进 `MapStyle`**：`MapStyle` 是持久化值 + URL 维度，`FOLLOW_THEME` 没有 URL，混入会让 `styleUrl()` 出现 null 分支并污染既有键语义。
- **chip 口径**：`SettingsLogic.mapStyleChoice` 跟「用户表态」走，不跟「生效样式」走——手动选彩色后深色下高亮仍停在彩色。
- **布局**：四 chip 用 `FlowRow`（窄屏/大字体换行，不顶出屏幕）。
- **验收**：四选可切；「跟随主题」下切深色 → 底图自动变深色；切「彩色」→ 固定且深色不再覆盖；再点「跟随主题」→ 恢复自动；明暗/皮肤/地图来源均不被重置。
