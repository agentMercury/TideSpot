## 1. 换肤与主题工程化（SKIN-1/2/3 + OPT-A-03/09）

### SKIN-1 · 皮肤 token 抽象层　P1　未开始
- **现状**：`VintageOutdoorTheme.kt` 是「详情页专用薄主题」，4 套 `ColorScheme` 写死在文件里；无 `TideSpotSkin` 数据类/注册表/`LocalSkin`。
- **目标**：抽出 `TideSpotSkin` + `SkinPalette`（海/陆 × 浅/深四件套）+ 注册表 `TideSpotSkins.all` + `LocalSkin`；A 成为首个实例。
- **验收**：详情页视觉**不回归**（对比 pilot 截图）；`TideSpotSkins.byId("a-vintage")` 可取到。
- **落点**：`core/ui/theme/TideSpotSkin.kt`、`LocalSkin.kt`（新增）。
- **依据**：`SKIN-DEV-STANDARD.md` §4.1/§4.2/§9。

### SKIN-2 · 全局主题注入　P1　未开始
- **现状**：全局 `TideSpotTheme`（`MainActivity:87`）只有 `darkTheme`；详情页额外包 `VintageOutdoorTheme`（`:357`）。
- **目标**：`TideSpotTheme(skin, water, darkMode)` 全 App 生效；按点位水体 + 皮肤 + 明暗派生。
- **验收**：切三轴全屏一致、无单屏漏切。
- **落点**：`TideSpotTheme.kt` 改造；`MainActivity` 注入。

### SKIN-3 · 三轴持久化　P1　未开始
- **现状**：`SettingsKeys` 仅 `UNIT_SYSTEM/API_KEY/MAP_STYLE`；无 `skinId/themeMode`。
- **目标**：新增 `settings.skinId`、`settings.themeMode`；冷启动分别回放；互不重置。
- **落点**：`feature/settings/.../SettingsState.kt`、`app/.../AppSettings.kt`。

### OPT-A-03 · 应用内明暗三选　P1　未开始
- **现状**：`TideSpotTheme.kt:89` `darkTheme = isSystemInDarkTheme()`，**仅跟随系统**；设置页无明暗选项。
- **目标**：设置「显示」版块加「深色模式：跟随系统/浅色/深色」三选，持久化注入主题；底图随深色切样式。
- **验收**：三选持久化；与系统解耦；冻结语义色对比度 ≥4.5:1。
- **落点**：`SettingsState.themeMode`；`MainActivity` 传 `darkTheme=`；`MapScreen` 样式联动。

### OPT-A-09 · 换肤选择页 + 设置入口　P2　未开始（设计入口已画）
- **现状**：设计侧设置页「外观·皮肤」入口已画（`screens/settings.png`）；**Kotlin 无入口、无选择页、无皮肤数据结构**（依赖 SKIN-1/2/3）。
- **目标**：设置「显示」内加「外观·皮肤」入口 → 选择页（首版仅 A 可选 + 「敬请期待」占位）→ 切换全屏生效。
- **验收**：入口可达；仅 A 可选；占位不可误点；切换仅改视觉、不动冻结契约；三轴正交。
- **落点**：`feature:settings` 新选择页 + 入口行；`skinId` 持久化。

## 3. 设置页功能改版 & 其它功能

### OPT-A-01 · 删除「用例 / 物种 / 权重」　P2　未开始
- 现状：`SettingsScreen.kt:157` 仅占位。目标：删除整块版块 + 占位 Composable + 中英文案；**评分默认用例/权重逻辑不变**（只下线入口）。
- 验收：设置页无该版块；无死代码/死资源；评分默认不回归。

### OPT-A-02 · 删除「API Key（可选）」　P2　未开始
- 现状：`SettingsScreen.kt:165` 有输入框+保存（写 SharedPreferences）。目标：删除版块/输入/保存/文案；已存 Key 一次性清理（不入库不上传）。
- 验收：无该版块/角标/输入框；`SettingsState.apiKey` 相关删除；隐私披露同步移除。

### OPT-A-06 · 补 fetch_log（频控/请求可见）入口　P2　未开始
- 现状：设计稿「数据与网络」含该项；`SettingsScreen` 无入口。目标：只读请求日志（源/时刻/状态/是否命中频控），不泄露密钥、可清空。
- 验收：入口可达；不泄露密钥；频控可见。

### OPT-A-04 · 地图页 Top10 入口语义对齐　P1　未开始
- 现状：SRS 口径 = Top10 进收藏页展开跨点 Sheet；工程 `MapScreen` **无** Top10 入口；设计稿地图页有横幅。
- 目标：地图横幅改「跨点 Top10」跳收藏（或移除本点暗示）；无 ≥60 分窗口走兜底文案不造假。
- 验收：横幅跳转与文案一致；跨点每项带点位名；时段四 Chip 可用。

### OPT-A-05 · 四态视觉强调等级对齐　P2　未开始
- 现状：`DetailScreen.kt:202` 有 `StaleBanner`（3h/6h TTL、≥48h 不可用），**无常四态分级色**。
- 目标：四态定义视觉等级 + 文案单源（48h 警示色且禁数据操作；陈旧显缓存时刻；离线/分维降级可读缓存）；色取 token，语义不变。
- 验收：文案取 `TideSpotStrings`；48h 最醒目；不遮挡 Tab/DaySelector。
