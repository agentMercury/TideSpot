## 2. 本批发现的缺陷与修复（CHG-95 r8）

- **现象**：`DetailScreen.kt` 五 Tab 的「选中下划线」在 v1.21.0 真机上完全没有上屏。把 Tab 栏裁剪放大 2× 后，
  浅色（选中钓鱼指数）与深色（选中钓鱼指数）两张图都只有鱼图标 / 文字颜色变化，底部无任何横线；
  切到「潮流」Tab 同样没有。整条描边容器与 40dp 高度是好的。
- **排除误判**：不是颜色太浅——A 皮肤浅色 `tertiary = #D9A734`（芥末黄）、深色 `#80CBC4`（亮青），
  在米色 / 深蓝纸底上都应清晰可见；放大图里连浅色痕迹都没有。
- **根因**：旧实现把 `Modifier.drawBehind { drawLine(...) }` 挂在 **M3 `Surface` 的外层 modifier** 上，
  被 `Surface` 自身的 `clip(shape) / background(color)` 绘制链盖掉，属于「纯绘制装饰挂错层级」，不是布局测量问题。
- **修法**（`feature/detail/.../DetailScreen.kt`，CHG-95 r8）：Surface 的 modifier 去掉 `drawBehind`（删掉不再使用的
  `Offset` import），改为在 Tab 的 `Column` 内 `Text` 之后加一个**显式纯绘制 Box**：
  `32dp × 2.5dp`，`background(if (selected) tabUnderline else Color.Transparent)`。
  Box 无文字、不可点击、不消费触摸，颜色仍取 `colorScheme.tertiary`（深浅自适应）。
- **复验（v1.21.1）**：浅色「钓鱼指数」下方出现芥末黄短横线、深色出现亮青短横线；
  切到「潮流」后横线**移动到潮流下方、钓鱼指数下方消失**。修复通过，且未推动下方内容。
  证据 `crop-tab-13-dark-fixed.png` / `crop-r8-15-detail-light-fixed.png` / `crop-r8-16-detail-tab-tide-fixed.png`，
  并排图 `pairs-r8/06-tab-underline-fix.jpg`（左 1.21.0 无线 / 右 1.21.1 有线）。
- **版本**：按 `HANDOVER_V115.md` §0.6「修 bug = 小版本」升 `versionCode 28→29` / `versionName 1.21.0→1.21.1`，
  重新 `assembleRelease` 出包并覆盖安装复验；**第一位版本号未动**。
