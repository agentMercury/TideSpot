## 2. 导航模型（地图优先，CONFLICT-01 已关闭）

```
AppRoot = Scaffold(contentWindowInsets=0) + when(page)
  MAP(FAVORITES/DETAIL/SETTINGS)   ← 无底部 NavigationBar
S01 地图选点（准星 = 唯一选点真源）
 ├─ 星标 ─────────────→ OV05 气泡卡 ──[查看详情]──→ 先收藏再进详情
 ├─ [收藏] ───────────→ OV03 确认收藏对话框
 ├─ 收藏入口 ─────────→ S08 收藏列表 ──→ S02 详情（携带原坐标）
 ├─ 设置入口 ─────────→ S09 设置与隐私
 ├─ Top10 入口 ───────→ OV01 跨点 Top10
 └─ [确定] ───────────→ S02 详情
        ├─ Tab1 钓鱼指数 ──点小时──→ S03 因子分解
        ├─ Tab2 潮流(水位) ─[校准]─→ C14 现场校潮
        ├─ Tab3 天气
        ├─ Tab4 水质 ─[录入实测]──→ OV04 录入 Sheet
        ├─ Tab5 风浪(湖面风与水温)
        └─ 常驻免责入口 ──────────→ OV02 免责 BottomSheet（恒 5 条）
```

**Tab 渲染序恒 5 项**：钓鱼指数 → 潮流(水位) → 天气 → 水质 → 风浪（`titlesInTabOrder`）。点星标 / 搜索结果 / 地图中心点击都不得绕过 C01 准星真源。

## 5. 24 行全量数值表

每张图必须有等价数值表（N-7）。列：时刻（`HH:00`，选点墙上时间）/ 数值（带单位、等宽右对齐）/ 档位 / 置信 / 窗口标记（≥80，与图上薄荷窗格一致）。

- **null 显示「—」，禁止显示 0**；图表上同步断线不连线。
- 档位列取 `band.labels`，与色块文字一致；TalkBack 逐行读时刻+数值+单位+档位+置信+是否窗口。
- 固定 24 行可滚动；示例行见 `screens.json → numeric_table`（示例值非业务数据）。

## 6. 深色（独立设计，非反色）

- 全套 9 屏按 `theme.dark / surface.dark / text.dark / border.dark` 换色（DV04）；底图压暗（brightness .42 / saturate .6）。
- L2 抬升用 `surfaceVariant #1E2C3A` 分层；**冻结语义色不改值**，靠文字标签 + 深色描边保证 ≥4.5:1。
- 样张：DV01 钓鱼指数屏（`assets/v3/screen-dv01-dark-score.png`）、DV02 离线/陈旧/48h 条、DV03 分维降级卡（规则见 tokens）。

## 7. Android 16 edge-to-edge 标注

| 项 | 值 | 说明 |
|---|---|---|
| 状态栏占位 | 58 dp | 仅稿件表现值 |
| 顶部浮层起点 | y ≥ 68 dp | 避开状态栏 |
| 底部手势条预留 | ≥ 24 dp | 六个组件必须 padding |
| 实现口径 | `WindowInsets.statusBars` / `navigationBars` | 工程 `contentWindowInsets=0` 全屏铺入；**禁止把 58/24 写死** |
| 验收机型 | **AAK-AN00 / Android 16** | v2「荣耀 Win RT / 无 GMS 单机」作废；定位双通道 |

需预留底部余量：底部信息条、Top10 入口、Sheet 内容底、对话框按钮、免责 Sheet 末条、免责入口条。P2 遗留：地图未铺入系统栏区，随下次 UI 批次处理。
