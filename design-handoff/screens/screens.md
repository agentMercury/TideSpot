**注意**：🔶 结构稿用于表达结构与占位，不是逐屏确认过的像素级精稿；配色、圆角、字阶与组件细节一律以 ✅ 基准屏（尤其 S02）+ `tokens/design-tokens.json` 为准。两者冲突时以 token / 组件规范为准。

## 2. 导航模型

```
S01 地图选点（准星 = 唯一选点真源）
 ├─ [收藏] ─────────────→ OV03 确认收藏对话框
 ├─ 收藏入口 ────────────→ S08 收藏列表 ──→ S02 详情（携带原坐标）
 ├─ 设置入口 ────────────→ S09 设置与隐私
 ├─ Top10 入口 ──────────→ OV01 Top10 BottomSheet
 └─ [确定] ─────────────→ S02 详情
        ├─ Tab 1 → S04 湖面风与水温 / 风浪
        ├─ Tab 2 → S05 天气
        ├─ Tab 3 → S02 钓鱼指数 ──点小时──→ S03 因子分解
        ├─ Tab 4 → S06 水质
        ├─ Tab 5 → S07 潮流 / 水位 ──[校准]──→ C14 现场校潮
        └─ 常驻免责入口 ──→ OV02 免责 BottomSheet（恒 5 条）
```

**没有通用底部 Tab Bar**。顶部浮层 + 准星 + 底部信息条 + Top10 入口是首页固定的四件套；五维 Tab 只存在于详情页。

## 5. 24 行全量数值表

每张图必须有等价数值表（N-7）。列定义：时刻（`HH:00`，选点墙上时间）/ 数值（带单位、等宽右对齐）/ 档位 / 置信 / 窗口标记。

- **null 显示「—」，禁止显示 0**；图表上同步断线不连线。
- 档位列取 `band.labels`，与色块文字一致。
- TalkBack 逐行读法：时刻 + 数值 + 单位 + 档位 + 数据置信 + 是否窗口。
- 表格固定 24 行（对应 24 点），可滚动到全量。示例行见 `screens.json → numeric_table`。

## 6. 深色

- 全套 9 屏按 `theme.dark / surface.dark / text.dark / border.dark` 换色（DV04）。
- **冻结语义色不改值**（五档色 / 六徽标）；靠文字标签 + 深色描边保证对比 ≥ 4.5:1。
- 已画出的深色样张：DV01 钓鱼指数屏、DV02 离线陈旧条、DV03 分维降级卡（`assets/dark-adaptation.svg`）。

## 7. Android 16 edge-to-edge 标注

| 项 | 值 | 说明 |
|---|---|---|
| 状态栏占位 | 58 dp | 仅稿件表现值 |
| 顶部浮层起点 | y ≥ 68 dp | 避开状态栏 |
| 底部手势条预留 | ≥ 24 dp | 五个组件必须 padding |
| 实现口径 | `WindowInsets.statusBars` / `navigationBars` | **禁止把 58/24 写死进代码** |
| 验收机型 | 荣耀 Win RT / Android 16 / 无 GMS（单机口径） | — |

需要预留底部余量：底部信息条、Top10 入口、BottomSheet 内容底部、对话框底部按钮、免责 Sheet 末条。

## 8. 每屏验收要点速查

| 屏 | 必须满足 |
|---|---|
| S01 | 准星落点后信息条非空；对话框不遮挡信息条；陆地点提示可见 |
| S02 | 五档冻结色 + 档位文字；图表可切数值表；免责入口常驻可达 |
| S03 | 原始输入 16 项齐全；禁止 parse 否决文案；ΠV 触发行可辨识 |
| S04 | 不出现 `wave=0`；内陆不显示潮汐专属指标；免责 1/2 条可达 |
| S05 | 免责第 2 条原文完整；安全判定不表述为官方预警 |
| S06 | 不可用显示「—」；2×2 卡高 ≥112 dp 不裁切；免责第 4 条完整 |
| S07 | 内陆不画潮汐曲线；校正前后可区分；未校正不假装已校正；免责第 5 条可达 |
| S08 | 空态引导回地图；点击行携带原坐标 |
| S09 | 六版块齐全；逆地理总开关存在；逐源披露；不声明「零数据传输」 |
