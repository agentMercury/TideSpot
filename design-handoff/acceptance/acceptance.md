## 2. 全局验收

- [ ] 主题明暗跟随系统，由 `TideSpotTheme` 统一提供；Shapes/Typography 取工程既有 token
- [ ] 语义色（五档 / 六徽标）取 Kotlin 单源，未进 `MaterialTheme`、未派生深色副本
- [ ] **CHG-56**：浅色次要文字 `#556579`（≥4.5:1），全包无 `#8A9DB0`；深色正文 ≥4.5:1
- [ ] 深色为独立设计（底图压暗 + surfaceVariant 分层 + 主色提亮），非反色；冻结色值不变
- [ ] v3 薄荷点缀克制（每屏 ≤3 处），未替代五档冻结色、未满屏铺
- [ ] 所有档位、徽标均色块 + 文字同时出现（N-7）
- [ ] 每张图有等价数值表；24 行表 null 显示「—」，图表断线不连线
- [ ] 免责恒 5 条、顺序 1..5、原文完整、可滚动、常驻入口可达
- [ ] 所有可点元素命中区 ≥ 48 dp
- [ ] **Tab 渲染序 = `titlesInTabOrder` 恒 5 项**（钓鱼指数→潮流(水位)→天气→水质→风浪），无手工组数组

- [ ] 项目约束：无 XML layout，全部 Compose；未改 `ScoreBands` / `ConfidenceBadge` / `TideSpotTheme` 取值
- [ ] 改 UI 前跑现有测试（V1.15 八模块 BUILD SUCCESSFUL / 573+ 测试），零行为漂移
