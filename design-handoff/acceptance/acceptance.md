# 标注说明与验收清单

> 本文件用于「按本包落地后」的自检。机器可读的规格分别在 `tokens/`、`components/`、`screens/`、`copy/` 的 JSON 中。
> 本包为设计侧交付，不含 Compose 代码与可编译资源；验收对象是**实现结果**，不是本包文件。

## 1. 标注规则（怎么读设计稿里的数）

| 标注 | 含义 |
|---|---|
| 所有尺寸 | dp；设计稿 390 × 844 为 1x，1px = 1dp |
| `box = x,y,w,h` | 相对屏幕左上角，`screens/screens.json` 的 `layers[].box` |
| 366 / 358 | 主卡片宽（左右各 12 dp）/ 次级内容宽（左右各 16 dp） |
| 58 dp 状态栏、24 dp 手势条 | **稿件表现值**，不是代码常量；实现走 `WindowInsets` |
| 色值 | 主题色取 `TideSpotTheme`，语义色取 `ScoreBands` / `ConfidenceBadge`，均不得在 UI 层重写 |
| 文案 | `copy/copy.json → keys`；`frozen` 引用工程常量，`design_proposed` 需产品确认 |
| 示例数值 | 版式示意，非业务数据，禁止当作真实值实现 |
| 🔶 derived 稿 | 按规格推导的结构稿，表达层级与占位；视觉细节以 ✅ 基准屏 + token 为准 |

## 2. 全局验收

- [ ] 主题明暗跟随系统，且由 `TideSpotTheme` 统一提供
- [ ] 语义色（五档 / 六徽标）取 Kotlin 单源，未进 `MaterialTheme`、未派生深色副本
- [ ] 深色下冻结色值与浅色一致，靠文字标签 / 描边 / 底色保证对比 ≥ 4.5:1
- [ ] 所有档位、徽标均色块 + 文字同时出现（N-7）
- [ ] 每张图有等价数值表；24 行表 null 显示「—」，图表断线不连线
- [ ] 免责恒 5 条、顺序 1..5、原文完整、可滚动、常驻入口可达
- [ ] 所有可点元素命中区 ≥ 48 dp
- [ ] 项目约束：无 XML layout，全部 Compose；未改 `ScoreBands` / `ConfidenceBadge` / `TideSpotTheme` 的取值
- [ ] 现有测试通过（M6 退出快照 573 测试通过），零行为漂移

## 8. 本包不包含

- 对 `tidespot-android/` 下任何源码的修改。
